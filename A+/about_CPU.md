# CPU = Central Processing Unit / Processor / micro-Processor
In a computer, CPU do all about the processing and it need to work with RAM, special processor (GPU) and also I/O devices to give the instruction and show the result.
At 1971, the first CPU is invented by Intel Company. It is Dip Type 4004 processor with the 4 bits architecture. CPU use the machine language which is all about on/off, presence/no-presence, 1/0 with binary system.

* machine language = on/off, presence/no-presence, 1/0
* binary system = if V on => 1 (1bit) / V off => 0 (1bit)

## Units of Computer Memory Measurements
* 8 bits (b) = 1 Byte (B)
* 1024 B = 1 KiloByte (KB)
* 1024 KB = 1 MegaByte (MB)
* 1024 MB = 1 GegaByte (GB)
* 1024 GB = 1 TerraByte (TB)
* 1024 TB = 1 PetaByte (PB)
* 1024 PB = 1 ExaByte (EB)
* 1024 EB = 1 ZettaByte (ZB)
* 1024 ZB = 1 YottaByte (YB)
* 1024 YB = 1 BrontoByte
* 1024 BrontoByte = 1 GeopByte

  eg=>May Theint San= 14 * (8 bits) = 112 bits/14 Bytes (each character represent 8 bits)

  CPU is make with transistor/semiconductor ( 3 pin legs named Emitter, Base, Collector)

## Which CPU is better?
  * logically = compare the performance/ speed of processing
  * physically = compare transistor count
On modern Integrated Circuit (IC) chips use MOSFETs (Metal-Oxide Semiconductor Filed-Effect Transistors) / MOS transistors
AT 2021, Apple's ARM-based M1 MAX Systems has 57 billion MOSFETs micro-processor. It is the largest transistor counts at that time.

## CPU housing
Ceramic became on of the option for the CPU housing. Ceramic can be got by giving the temperature about 2400°C to the mud and purifying. So that ceramic can be resist the temperature over 2000°C. So in some of the racing care like formula1 use this ceramic combine with carbon for the heat-resistance brake. 
The CPU's heat is normally not over 100°C but it is still the best option to protect its silicone chipset. For some reasons like more expensive than other to produce, breakable for falling from the high or by some pressure, some CPU was changed into organic substrate.

## CPU components
1. Chipset => manufacturer (Intel, AMD = Advanced Micro Devices, Qualcomm)
   * in here Qualcomm company is lately founded than the others two companies. It starts invented CPU for phone by 2010s. Around 2023, it released CPU for laptop which is faster, use less power usage and less heat release. So in some laptop with Qualcomm CPU has no fan inside.
2. IHS (Integrated Heat Spreader)
   * 2 main purposes => to protect silicone chipset from dust and else, to spread heat from silicone chipset to other cooling system
3. Socket Type
   * DIPP (dual-line pin package)
   * PLCC (plastic lead circuit carrier)
   * LGA (lan Grid Array)
   * PGA (Pin Grid Array)
   * BGA (Ball Grid Array)
4. Cooling System
   * Active => air cooling / liquid cooling
   * Passive => only heatsink
5. Power Connector => +12V P4 connector/port
